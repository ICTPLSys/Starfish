# Figure 9: application performance

Complete [installation](../../docs/INSTALL.md) and
[server configuration](../../docs/MULTI-SERVER.md), then run from
`artifact-evaluation/`:

```bash
bash scripts/figure9/run.sh
```

To plot the collected data again:

```bash
bash scripts/plot.sh figure9
```

Results:

- Logs and configurations: `results/figure9/batch-*/runs/`.
- Measurements: `results/figure9/batch-*/figure9.csv`, also copied to `data/figure9.csv`.
- Figures generated by the run: `results/figure9/batch-*/figure/`.
- Replotted figures: `results/figures/figure9/figure9.png` and `figure9.pdf`.
